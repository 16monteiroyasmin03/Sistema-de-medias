# Calculadora de Médias Escolares em C 📚

## 📌 Sobre o projeto

Este projeto foi desenvolvido em C com o objetivo de calcular as médias das matérias do ensino médio regular da UNIVAP, seguindo o sistema de avaliação utilizado pela escola.

A calculadora permite que o aluno informe suas notas e confira a média calculada, ajudando a verificar se as notas foram lançadas corretamente no site escolar.

**Observação:** o programa contempla as matérias do ensino médio regular e não realiza cálculos das matérias do ensino técnico.

## ⚙️ Funcionalidades

- Cálculo de médias de acordo com o tipo de avaliação de cada matéria.
- Validação das notas informadas pelo usuário.
- Cálculo da pontuação necessária para atingir a média 6.
- Exibição dos pontos acima da média.
- Possibilidade de calcular a média de várias matérias sem reiniciar o programa.

## 💻 Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h` para entrada e saída de dados.
- Biblioteca `string.h` para comparação dos nomes das matérias.

## 🧠 Conceitos de programação utilizados

Durante o desenvolvimento, foram utilizados:

- **Funções:** para organizar e realizar os diferentes cálculos de médias.
- **Condicionais (`if`, `else if` e `else`):** para identificar a matéria e selecionar a fórmula correspondente.
- **Laços de repetição (`while` e `do while`):** para validar as entradas e permitir novos cálculos.
- **Entrada e saída de dados (`scanf` e `printf`):** para interagir com o usuário.
- **Variáveis:** para armazenar notas, médias e resultados.
- **Validação de dados:** para impedir que notas fora dos intervalos definidos sejam aceitas.

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `.c` em uma IDE ou editor compatível com C.
3. Compile e execute o programa.
4. Informe a matéria e as notas solicitadas para visualizar o resultado.

Este projeto foi desenvolvido para colocar em prática os conhecimentos adquiridos em programação, especialmente em linguagem C, além de criar uma solução para uma necessidade real do ambiente escolar.
